# 小乐 · Ren'Py 游戏实时修改器（RenPyCheat）v1.1.0

给 Ren'Py 游戏（很多 Galgame / SLG / 文字冒险都用这个引擎）外挂一个**实时修改面板**：
游戏开着的时候，直接在电脑上改金钱、好感、物品、解锁画廊，改完立刻生效，不用退出游戏。

> Electron / NW.js 内核的 ADV（TyranoScript、RPG Maker MV/MZ）也支持，用法见「三 · 补充」。

## 一、这个工具是干什么的

游戏里的数值（金钱、体力、好感、物品数量、CG 解锁状态…）平时只能靠反复刷，
这个工具把这些数值**列出来给你直接改**，改完游戏里马上就能看到。

它和「存档修改器」的区别：

| | 存档修改器 | 本工具 |
|---|---|---|
| 什么时候改 | 先退出游戏，改存档文件，再进游戏 | 游戏运行中直接改，改完立即生效 |
| 要不要备份存档 | 要，改坏了存档就废了 | 不用，不碰存档文件 |
| 上手难度 | 要会找存档、找字段 | 拖进游戏目录，点几下按钮 |

## 二、三步就能用

1. **打开工具**：下载 `RenPyCheat_v1.1.0.zip`，解压到任意文件夹，双击 `RenPyCheat.exe`。
2. **选游戏**：把游戏的启动程序（`.exe`）或者游戏根目录（里面有 `game` 文件夹的那个目录）**直接拖进左上角的输入框**，也可以点「浏览」选择。
3. **装模块 → 启动**：
   - 点「安装注入模块」（工具会往游戏目录里放一个小脚本，用来和工具通信）
   - 点「启动游戏」
   - 等右上角状态从「未连接」变成绿色「已连接」，就可以开始改了。

> 重要：**装完模块必须重启游戏才生效**。如果游戏已经在运行，先关掉游戏，再点「启动游戏」。
> 游戏已经开着了？点「附加进程」，选中那个游戏进程也能连上。

## 三、每个页签能干什么（全部功能说明）

### 1. 收藏修改
把你经常改的那几个数值收藏起来（比如「金钱」「体力」）。
下次打开同一个游戏，这些项目会自动带出来，点一下就改，不用每次重新找。

### 2. 变量列表
游戏里**所有能改的数值**都列在这里：金钱、天数、体力、好感、剧情标记……
双击某一行的「当前值」就能改成你想要的值。
看不懂英文变量名？后面几列会自动显示中文名（能识别就显示）。

### 3. 数值搜索
游戏里显示「金钱 1200」，但你不知道这 1200 存在哪个变量里？
在「数值搜索」里输入 `1200` 搜一下，就能定位到它，然后直接改。
（先搜一次、在游戏里让数值变一下、再搜一次，可以缩小范围，找得更准。）

### 4. 角色属性
按角色查看和修改「好感 / 关系 / 亲密度」这类数值，适合攻略向游戏。
可以多选后一次性把几个角色的好感都设成同一个值。

### 5. 属性识别
自动扫描游戏里「谁对谁的好感」这种结构（比如 `角色A.好感`），
识别出来并标上中文名，避免你在变量列表里一个个翻。
识别不准时可以手动指定，或者回到「角色属性」页按角色改。

### 6. 物品
背包 / 仓库里的物品和数量。可以直接把某个物品改成 99 个，或者把没拿到的道具加上。
物品名会尽量显示成中文（工具会读取游戏的中文翻译文件）。

### 7. 画廊 · 解锁
解锁游戏里的 CG、回想、特典、结局图鉴这类「画廊内容」。
常见做法是把「已解锁」的开关全部打开；不同游戏写法不一样，工具会把能识别到的都列出来。

### 8. 赞助 · 礼包码
有些作者会做「赞助码 / Patreon 会员 / 礼品码」来解锁额外内容。
这一页会自动找出这类开关，**一键解锁**；点错了可以「撤销上次解锁」还原。

### 9. 修改记录
记录你改过的每一项：原来多少、现在多少、什么时候改的。
改乱了想还原，对照这里就能知道原始值，重启工具后记录也还在。

### 10. 数值锁定
把某个数值「钉死」。比如把金钱锁成 9999，游戏里花掉又马上变回 9999。
适合需要反复消耗的数值；不想要了在这里解除锁定即可。

### 11. 持久化数据
游戏里「跨存档保留」的数据（persistent）：画廊解锁、结局记录、设置项。
这类数据改完对**所有存档**都生效，适合一次解锁全部内容。

### 12. 汉化 · 文本
直接读写游戏里的 `.rpy` 脚本文本，配合汉化补丁使用。
也能提取游戏自带的中文翻译，让物品 / 角色名显示成中文。

- **扫描自动去重**：同一句原文只保留一条，几万行的游戏也不会重复机翻。
- **机翻缓存**：译文缓存在游戏目录 `zz_xl_mt_cache.json`，重试 / 换引擎 / 二次生成直接复用；
  卸载汉化会一并清理。
- **原文语言自动判断**：英语、日语、韩语、俄语、西语、法语、葡语、德语都能识别，
  韩文 / 日文游戏不再被当成英语翻译。
- **占位符保护**：`[变量]`、`{标签}` 译完自动还原，丢失会标红提示，可单独重试；
  本身就是中文的台词会自动跳过，不浪费额度。

### 13. 日志
工具的运行记录：连接了哪个端口、改了哪些值、哪里报错。
出问题时把这页内容截图发到 Q 群，方便排查。

### 14. 更新日志
每个版本改了什么，一目了然。

### 15. 关于 · 赞助
版本号、作者、问题反馈 Q 群、爱发电主页，以及微信 / 支付宝收款码。
点「检查更新」可以手动检测新版本。

## 三 · 补充：Electron / TyranoScript / RPG Maker 游戏

除了 Ren'Py，这个工具也能改 **Electron / NW.js 内核**的 ADV（TyranoScript、RPG Maker MV/MZ 等）：

- **不用装注入模块**：这类游戏本身就是内嵌 Chromium 的程序，工具启动时会给它加上调试参数，
  直接连进去读写变量，不会往游戏目录写任何文件。
- **必须用工具里的「启动游戏」按钮启动**：调试端口只在启动那一刻打开，游戏已经开着了就接不上了。
- **TyranoScript 完整支持**：变量列表 / 数值搜索 / 数值锁定 / 收藏修改 / 修改记录之外，
  角色属性、我的数据（金币与成长数值）、物品背包、任务、画廊解锁、赞助码、持久化数据
  这些页签也会开放，并自动读取 Tyrano 的四类变量根：
  「游戏变量 f」（随存档保存）、「系统变量 sf」（全存档共用）、
  「临时变量 tf」、「地图变量 mp」。
- **RPG Maker MV/MZ**：开放变量列表 / 数值搜索 / 数值锁定 / 收藏修改 / 修改记录，
  变量与开关会显示游戏里配置的名称；其余页签自动置灰。
- **汉化页只对 Ren'Py 有效**（它处理的是 .rpy 文件）。
- Tyrano 的物品 / 画廊 / 好感等页面是按变量名和常见结构自动识别的，不需要改写游戏；
  如果某个游戏用了特殊的命名，可先用「数值搜索」按名字找到变量再改。
- 如果进去只看到几条系统变量，说明游戏还没开局，先新建/读取存档，变量出现后再刷新列表。
- Tyrano 的存档若使用 WebStorage，则「备份存档」无法复制为文件；使用文件存档的游戏会备份
  `tyrano/data/savedata`（或 `data/savedata`）。

## 四、侧边栏其他功能

- **安装 / 卸载注入模块**：往游戏目录放一个通信脚本，卸载就是删掉它，不影响存档。
- **启动游戏 / 附加进程**：启动游戏后自动连接；游戏已经在跑就手动附加。
- **关闭存档保护**：Ren'Py 会校验存档签名，外部改过的存档可能读不了。
  这个按钮会临时关掉校验（会先备份游戏文件，可随时恢复）。
- **开启跳过未读文本**：打开「未读文本也能跳过」，方便快速过剧情。
- **开启回退功能**：滚轮上 = 回退上一句、滚轮下 = 前进；顺便解除游戏对回退的限制。

## 五、常见问题

**Q：一直显示「未连接」怎么办？**
1. 确认点过「安装注入模块」，并且**安装之后重启了游戏**；
2. 游戏已经开着但没连上 → 点「附加进程」，选中游戏进程；
3. 看看侧边栏「通道端口」是不是被别的程序占了，换一个端口再装一次模块。

**Q：改了数值，游戏里没变化？**
有些数值是「显示时才重新读」，改完切一下场景（存档/读档、进出菜单）就会刷新；
如果还是不变，可能是这个数值只是显示用的副本，去「变量列表」里搜真实的那一项。

**Q：会不会弄坏我的游戏 / 存档？**
工具只在游戏目录里增加一个注入脚本，以及改存档保护相关的引擎文件（改前会备份）。
它不会修改你的存档内容——改的是游戏运行时内存里的数值。

**Q：杀毒软件提示风险？**
工具是用 PyInstaller 打包的单文件程序，这类程序容易被杀软误报。
可以把它加入杀软信任名单，或者先在虚拟机里试运行；工具只在本机读写游戏目录，不联网、不上传数据。

**Q：更新怎么弄？**
启动工具时会自动检查 GitHub 上的新版本，有新版会弹窗显示更新内容，
点「立即更新」会自动下载、替换、重启，配置会保留。
